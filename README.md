# แมวระเบิด

เกมการ์ดแบบส่งเครื่องเล่นในเครื่องเดียว รองรับผู้เล่น 2-4 คน เขียนด้วย C++ 
tech stack ใช้ raylib เป็น GUI
และยึดโครงสร้างคลาสตาม Class Diagram ที่ให้มา

## วิธี Build

```sh
cmake -S . -B build
cmake --build build
```

## วิธี Run

```sh
./build/catbomb
```

## วิธีเล่น หรือ กฏการเล่น

- กดปุ่มเริ่มตั้งค่าบนหน้าแรก
- เลือกจำนวนผู้เล่น 2, 3 หรือ 4 คน แล้วคลิกช่องชื่อเพื่อแก้ชื่อ
- กดเริ่มเกมเพื่อเข้าสู่เกมจริง

ในแต่ละตาผู้เล่นจะสามารถเลือกที่จะใช้การ์ด หรือไม่ใช้ก็ได้ไม่จํากัดจํานวน 
แต่จะนับว่าจบตาของผู้เล่นต่อเมื่อ ผู้เล่นจั่วการ์ด

ความสามารถของการ์ด
1 . ระเบิด - เมื่อผู้เล่นจั่วได้การ์ดใบนี้ ผู้เล่นต้องออกจากเกม ถ้าไม่มีการ์ด/กู้ระเบิด/ 
2 . กู้ระเบิด - ใช้เมื่อปลดระเบิดเมื่อ จั่วได้การ์ด/ระเบิด/ เมื่อใช้เลือกว่าจะการ์ด/ระเบิด/ไว้ที่ไหนในกองการ์ด 
3 . ข้ามตา - ข้ามตาโดยไม่ต้องจั่วการ์ด
4 . ขอความช่วยเหลือ - ขอการ์ด 1 ใบจากผู้เล่นคนอื่น
5 . จั่วจากล่างสุด - จั่วการ์ดจากใต้กองการ์ด
6 . ดูอนาคต - ดูการ์ด 3 ใบบนสุดจากกองการ์ด 
7 . สับกอง - สลับการ์ดในกองการ์ด
8 . ยกเลิก - ยกเลิกความสามารถการ์ดของผู้อื่น /ข้ามตา - ดูอนาคต - สับกอง - ขอความช่วยเหลือ - จั่วการ์ดล่างสุด /
9 . การ์ดแมว - มีทั้งหมด 5 ใบ ความสามารถจะใช้ได้เมื่อ มีการ์ดเหมือนกันเป็นจํานวนดังนี้
    - 2 ใบ - ขอการ์ด 1 ใบจากผู้เล่นคนอื่น


## input
- สามารถใช้ชื่อของผู้เล่นก่อนเกมเริ่มได้
- Action ในเกมใช้ cursorMouse กด





โค้ดยังคงชื่อคลาสและหน้าที่หลักตาม Diagram เช่น `GameManager`, `Player`, `NetworkManager`, `Card`, `CardData`, `CardType`, `Effect`, `CatType`, `SpecialRule` และกติกาคอมโบแมวทั้งสามแบบ

## โครงสร้างไฟล์

- `src/main.cpp` เปิด raylib และรัน loop หลัก
- `src/GameModel.h` เก็บโมเดลเกมและกติกาการ์ด
- `src/GameUi.cpp` / `src/GameUi.h` เก็บหน้าจอและส่วนติดต่อผู้ใช้
- `src/AssetManager.cpp` / `src/AssetManager.h` โหลดรูปการ์ด ฉากหลัง เพลง และฟอนต์
